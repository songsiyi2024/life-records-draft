# 日迹

一个简洁、私人的生活记录网页草稿。

## 使用

双击 `index.html` 即可打开。

- 点击“写一条记录”，选择日期并填写简单描述。
- 记录默认保存在当前浏览器中，不会上传到网络。
- 在“数据备份”中可以导出 JSON 文件，也可以在以后导入恢复。
- 如果更换浏览器、清理浏览器数据或更换电脑，请先导出备份。

## 当前功能

- 按月份分组、按日期倒序展示
- 新增、编辑和删除记录
- 搜索日期和描述
- 本地保存
- JSON 导入和导出
- 手机与桌面响应式界面

照片功能暂未加入，后续可以为每条记录增加照片。

## 隐私提醒

如果以后把项目发布到 GitHub Pages，请不要把真实生活记录或私人照片直接写进仓库。当前版本的记录保存在浏览器本地，与网页代码分离。
